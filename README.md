
# SENTINEL-X AI PRO 🛡️

### Intelligent Cybersecurity Analysis Platform

SENTINEL-X AI PRO is an educational cybersecurity demonstration platform designed to identify suspicious patterns in URLs and email messages.

## 🚀 Features
- URL Threat Analysis
- Email Phishing Pattern Analysis
- Risk Score Demonstration
- Security Analysis History
- Responsive Dashboard
- User-Friendly Interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🎯 Project Objective
To create awareness about common online threats and demonstrate basic cybersecurity analysis through a simple web interface.

## ⚠️ Disclaimer
This is an educational prototype. It does not use live threat intelligence databases or guarantee that a URL or email is safe.
